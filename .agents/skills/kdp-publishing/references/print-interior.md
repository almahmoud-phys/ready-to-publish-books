# Print interior

Verified against official KDP help on 2026-08-15. Recheck the live pages before upload.

## Inputs that must be locked

- Binding: paperback or hardcover.
- Ink and paper.
- Left-to-right or right-to-left.
- Trim width and height.
- Interior bleed or no bleed.
- Page count from the final manuscript PDF at that trim.

Do not reuse the page count from a Letter/A4 review PDF or another trim. Reflow changes pagination, which changes the spine and full-cover width.

## 5 × 8 inch paperback

- KDP supports 5 × 8 in (127 × 203.2 mm).
- For black ink on cream paper, the supported page-count range is 24–776 pages.
- It is a standard compact-fiction size and is appropriate for a short graded reader when the typography remains comfortable.

KDP acceptance does not answer whether a book feels too short. Judge that from the final object: page count, spine, line length, font size, whitespace, price, and reader promise. Never inflate with filler or oversized type merely to create pages.

## Bleed and page size

- Covers always require bleed.
- Interior bleed is optional. Use it only when an image or background must reach the page edge.
- For a no-bleed interior, the uploaded PDF page size equals the chosen trim size.
- For an interior with bleed, follow KDP's current manuscript page-size formula; do not add bleed to the gutter edge.

## Minimum margins

For 24–150 pages, KDP's current minimum inside/gutter margin is 0.375 in (9.6 mm). Current minimum outside margin is 0.25 in without bleed or 0.375 in with bleed. These are rejection thresholds, not necessarily good book design; literary interiors often benefit from larger margins.

## Pagination and file checks

- Upload single pages, not printer spreads.
- Confirm the PDF page dimensions and page count directly.
- KDP calculates page count from the manuscript file and rounds an odd count up to an even production count.
- Embed fonts; remove comments, annotations, bookmarks, placeholder text, crop marks, and file security.
- Inspect the table of contents, blank pages, recto story openings, widows/orphans, clipped glyphs, and language-specific punctuation.
- Use Print Previewer, then order a physical proof.

## Decision heuristic for short books

Choose the smallest supported trim that preserves a professional font size and line length. For prose, a compact trim can improve pacing and perceived substance without changing content. Report both the actual word count and final production page count so the decision is transparent.
