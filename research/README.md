## Cross-shelf conclusion

1. **Data modeling — advance as a parent discovery branch, not a book.** The shelf is contested but
   below the repository's default saturation cutoff. It exposes multiple exact, potentially testable
   branches. Generic data modeling itself is occupied by established books and tool-specific guides.
2. **Data warehousing — keep as secondary.** The shelf has durable demand proxies and premium prices,
   but its visible leaders are established titles and publishers. A generic guide would not be
   enterable.
3. **Distributed systems — reject as a generic entry.** More than 30,000 results and an A-list-heavy
   first page make the parent phrase saturated; professional-judgment and verification burdens are
   also highest here.
4. **Data modeling for the sciences — reject as a seed.** The exact book has only six visible reviews,
   while the query falls back into generic data modeling/data-science results rather than forming a
   coherent direct shelf.
