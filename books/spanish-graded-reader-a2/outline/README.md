# Book architecture artifacts

This directory owns the book's content skeleton and hierarchy. It is separate from `tasks.md`:

- `outline/outline.md` is the master content architecture created by Stage 1 after Stage-0 GO.
- `outline/chapter_NN.md` is the binding contract for one chapter.
- `outline/outline.template.md` and `outline/chapter.template.md` define the minimum required detail.
- `tasks.md` tracks the work needed to create, verify, revise, and approve those artifacts.

The presence of templates does not satisfy Gate A. Only a fully populated, evidence-grounded
`outline/outline.md`, complete chapter contracts, and explicit human approval do.
